# Lead Scraper — Architecture

Two parallel implementations of the same pipeline. Same logic, same Gemini calls, same Azure Table as shared memory. Local mode is synchronous (dev/test); Azure mode is async fire-and-forget (production).

---

## Python Local Pipeline (`RUN_MODE=local`)

```mermaid
flowchart TD
    CLI["main.py\nCLI / stdin"]
    PIPE["lead_pipeline.py\nget_runner()"]
    RUNNER["LocalRunner\n.process()"]

    CLI --> PIPE --> RUNNER

    RUNNER --> F["filter_agent\ncity keywords + HOA rules\nvalues.yaml"]

    F -->|0 leads| EMPTY["return []"]
    F -->|N leads pass| T1["table_store\nupsert_filtered_lead ×N\nAzure Table: leads"]

    T1 --> CL["classifier_agent\nGemini classify_lead\ntool calling · retry · parse"]
    CL --> T2["table_store\nenrich_with_classification ×N"]

    T2 --> DISP["outreach/dispatcher\ndispatch_outreach()"]

    DISP --> A1["SubjectToAgent\nGemini generate_outreach"]
    DISP --> A2["SellerFinanceAgent\nGemini generate_outreach"]
    DISP --> A3["HybridAgent\nGemini generate_outreach"]
    DISP --> A4["FixAndFlipAgent\nGemini generate_outreach"]
    DISP --> A5["JVOrWholesaleAgent\nGemini generate_outreach"]
    DISP --> A6["BuyersLookingAgent\nGemini generate_outreach"]
    DISP --> A7["RegularAgent\nGemini generate_outreach"]
    DISP -->|Others| SKIP["skip — no outreach"]

    A1 & A2 & A3 & A4 & A5 & A6 & A7 --> T3["table_store\nenrich_with_outreach ×N"]
    T3 --> OUT["return merged results\n{classified + outreach}"]

    CL & A1 & A2 & A3 & A4 & A5 & A6 & A7 -->|HTTP POST| GEMINI[("Gemini API\ngenerative language")]
    T1 & T2 & T3 -->|MERGE| TABLE[("Azure Table Storage\nleads table\n— optional, skipped if\nno connection string")]

    style GEMINI fill:#4285f4,color:#fff
    style TABLE fill:#0078d4,color:#fff
    style EMPTY fill:#888,color:#fff
    style SKIP fill:#888,color:#fff
```

**Key points:**
- Runs entirely in-process — no Azure trigger needed
- Outreach agents run sequentially (one Gemini call per lead per category)
- Table writes are optional (skip gracefully if `AZURE_STORAGE_CONNECTION_STRING` not set)
- All prompts, categories, required fields driven by `values.yaml`

## Azure Logic App Pipeline (`RUN_MODE=azure` / Production)

```mermaid
flowchart TD
    BOT["Facebook Scraper Bot\nHTTP POST\n{items: [...]}"]

    BOT --> HUB

    subgraph HUB["filterProcessCreativeLeads — HUB Logic App"]
        direction TB
        FILT["Filter_Leads\nQuery action\ncity + HOA from values.yaml"]
        FILT -->|0 pass| R202A["Response 202"]
        FILT -->|N pass| LOOP["For each filtered lead\nsequential"]
        LOOP --> TW1["Upsert lead\n→ Azure Table"]
        TW1 --> GC["Call_Gemini_Classify\nHTTP · tool calling\nclassify_lead()"]
        GC --> PC["Parse classify args\nfunctionCall.args"]
        PC --> TW2["Upsert classification\n→ Azure Table"]
        TW2 --> COND{"category\n≠ Others?"}
        COND -->|No| SKIP2["skip"]
        COND -->|Yes| FIRE["HTTP POST to spoke\nDisableAsyncPattern\nfire-and-forget 🔥"]
        LOOP --> R202B["Response 202\n← hub returns here"]
    end

    FIRE -->|async, no wait| S1
    FIRE -->|async, no wait| S2
    FIRE -->|async, no wait| S3
    FIRE -->|async, no wait| S4
    FIRE -->|async, no wait| S5
    FIRE -->|async, no wait| S6
    FIRE -->|async, no wait| S7

    subgraph SPOKES["Spoke Logic Apps — HTTP triggered, zero idle cost"]
        S1["spoke-subject-to-outreach"]
        S2["spoke-seller-finance-outreach"]
        S3["spoke-hybrid-outreach"]
        S4["spoke-fix-flip-outreach"]
        S5["spoke-jv-wholesale-outreach"]
        S6["spoke-buyers-looking-outreach"]
        S7["spoke-regular-outreach"]
    end

    S1 & S2 & S3 & S4 & S5 & S6 & S7 --> GO["Call_Gemini_Outreach\nHTTP · tool calling\ngenerate_outreach()\ncategory system prompt"]
    GO --> PO["Parse outreach args"]
    PO --> TW3["Upsert outreach result\n→ Azure Table"]

    GO -->|HTTP POST| GEMINI[("Gemini API\ngenerative language")]
    GC -->|HTTP POST| GEMINI
    TW1 & TW2 & TW3 -->|MERGE| TABLE[("Azure Table Storage\nleads table\nshared across hub + all spokes")]

    style GEMINI fill:#4285f4,color:#fff
    style TABLE fill:#0078d4,color:#fff
    style SKIP2 fill:#888,color:#fff
    style R202A fill:#2e7d32,color:#fff
    style R202B fill:#2e7d32,color:#fff
```

**Key points:**
- Hub returns 202 immediately — never waits for spoke results
- Spokes are HTTP-triggered: **zero polling, zero idle cost**, only billed per execution
- Spoke trigger URLs are resolved at deploy time by Bicep (`listCallbackUrl()`), stored as hub parameter
- All Logic App workflow JSON generated by `sync.py --apply` from `values.yaml`
- One `azuretables` API connection shared by hub + all spokes

## Shared Config Layer

```mermaid
flowchart LR
    V["values.yaml\nfilter · classifier · outreach\nprompts · categories · required fields"]

    V -->|loaded at startup| FA["filter_agent.py"]
    V -->|loaded at startup| CA["classifier_agent.py"]
    V -->|loaded at startup| OA["outreach/base.py\n+ category agents"]

    V -->|sync.py --apply| WB["workflow_builder.py"]
    WB --> WJ["deploy/workflows/*.json\n8 Logic App definitions"]
    WJ -->|deploy.py| AZ["Azure Logic Apps"]

    style V fill:#f57c00,color:#fff
    style WJ fill:#546e7a,color:#fff
    style AZ fill:#0078d4,color:#fff
```

`values.yaml` is the **single source of truth** — changing a prompt, category, or required field updates both the Python agents (immediately on next run) and the Azure Logic Apps (after `sync.py --apply` + `deploy.py`).

## Azure Resources Deployed

| Resource | Type | Purpose |
|---|---|---|
| `releadscraper` | Storage Account | Table storage for pipeline shared memory |
| `leads` | Azure Table | Per-lead data: filtered → classified → outreach |
| `appversions` | Azure Table | Sync/deploy version tracking |
| `azuretables-lead-pipeline` | API Connection | Connector for all Logic Apps → Table |
| `filterProcessCreativeLeads` | Logic App | Hub: webhook ingest, filter, classify, route |
| `spoke-subject-to-outreach` | Logic App | Subject-To outreach agent |
| `spoke-seller-finance-outreach` | Logic App | Seller Finance outreach agent |
| `spoke-hybrid-outreach` | Logic App | Hybrid outreach agent |
| `spoke-fix-flip-outreach` | Logic App | Fix & Flip outreach agent |
| `spoke-jv-wholesale-outreach` | Logic App | JV or Wholesale outreach agent |
| `spoke-buyers-looking-outreach` | Logic App | Buyers Looking outreach agent |
| `spoke-regular-outreach` | Logic App | Regular outreach agent |
